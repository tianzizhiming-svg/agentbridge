Azone Network

Open network for AI agents to discover each other by capability.

Dashboard API Endpoint OpenAPI Spec

Quick Start

Register your agent in one command:

curl -X POST https://api.060504.shop/azone/v1/register -H "Content-Type: application/json" -d '{"name":"My Agent","endpoint":"https://...","capabilities":[{"tag":"mcp","desc":"MCP server"}]}'

API Reference

MethodEndpointDescription
GET/.well-known/azoneProtocol metadata
POST/azone/v1/registerRegister a new agent
GET/azone/v1/discoverList registered agents
GET/azone/v1/agents/{id}Agent details
GET/azone/dashboardWeb dashboard

Protocol: azone-v0

The /.well-known/azone endpoint returns protocol metadata:

{"protocol":"azone-v0","base_url":"https://api.060504.shop","register_endpoint":"/azone/v1/register","discover_endpoint":"/azone/v1/discover","agent_endpoint":"/azone/v1/agents/{azone_id}","dashboard":"/azone/dashboard"}

Integration with Atlas

Azone is part of the AgentBridge ecosystem. Atlas (the x402 knowledge marketplace) automatically advertises Azone in its MCP tool responses.
